# amzi-motors-concepts

Reference images for AMZI Motor Co. concept renders (Propane Utility Vehicle). Hosted publicly so image-edit models (RunPod Nano Banana 2 Edit) can fetch them by raw URL.

Author: Colin Bitterfield, colin.bitterfield@templeofepiphany.com
Created: 2026-11-07

## Layout
- refs/interior - cabin and dashboard style references
- refs/exterior - vehicle exterior references
- refs/engine - propane V8 engine bay reference
- refs/brand - AMZI logo
- panels - concept instrument panel faces (Layout C night is the chosen design)

Concept art only. No secrets or API keys belong in this repo.
